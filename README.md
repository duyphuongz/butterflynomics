# Butterflynomics

*First the panic. Then the pattern.*

Butterflynomics is an analysis and explanation tool for US economic news. It turns an article into an evidence-backed report and a map of how the news may spread through companies, sectors and indicators.

> Butterflynomics is an analysis and learning tool. Its output is not investment advice and does not predict stock prices.

**Status:** MVP under development. The landing page, the login and signup pages, and a login API are built. The analysis features are not implemented yet.

See the [product proposal](docs/butterflynomics-mvp-proposal-v0.3.md) for details.

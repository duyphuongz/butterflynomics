Logo wordmark Butterflynomics: chữ đậm với dấu chấm của chữ "i" là con bướm hình học, ký hiệu vuông cho favicon.

**Bạn cung cấp:** nền đúng loại. Wordmark thường trên `surface`, `surface-subtle`, `surface-sunken`; bản đảo trên `surface-inverse`; `mark` tự có nền đen.

**Dùng:** chiều cao tối thiểu 16px; chừa quanh logo ít nhất bằng chiều cao chữ "B"; file nằm ở nhóm tài sản Logo. Con bướm chỉ xuất hiện trong logo và `mark`.

**Không:** kéo giãn, đổi màu bướm, thêm bóng hoặc gradient, dùng con bướm làm họa tiết nền, hay chế lại logo bằng font thay vì dùng file.
